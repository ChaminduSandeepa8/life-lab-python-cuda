A UNIVERSE IN FOUR RULES

Life is a local decision.

Each cell looks at its eight neighbours. Every cell updates simultaneously from the previous generation.

01

Underpopulation

A living cell with fewer than two living neighbours dies.

02

Survival

A living cell with two or three living neighbours survives.

03

Overpopulation

A living cell with more than three living neighbours dies.

04

Birth

An empty cell with exactly three living neighbours becomes alive.

01 / CPU

2D arrays, less overhead.

Each cell is a uint8 value. NumPy adds eight neighbouring slices into a reusable array, then applies the life rule to the whole grid. A padded border implements wrap-around or dead-outside boundaries.

next = (neighbours == 3) OR
       (alive AND neighbours == 2)

A separate nested-loop implementation acts as an independent correctness reference.

02 / CUDA

One cell. One GPU thread.

A two-dimensional launch assigns a thread to each cell. Threads read the current grid and write a separate next grid. Buffers swap after each generation; the grid stays on the GPU throughout the experiment.

column, row = cuda.grid(2)
current, next = next, current

Adjacent x threads access adjacent columns. Warmup removes first-compilation costs from timing.
